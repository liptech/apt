Prefere conferir cada passo? O procedimento manual está logo abaixo — e o setup.sh pode ser lido antes de executar.

01 · setup

Instalação manual

Quatro passos. Funciona em Debian 11+, Ubuntu 20.04+ e derivados.

Instalar as dependências

sudo apt update
sudo apt install -y curl gnupg ca-certificates

Adicionar a chave de assinatura

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://{{DOMAIN}}/{{KEYRING}}.asc \
  | sudo gpg --dearmor -o /etc/apt/keyrings/{{KEYRING}}.gpg
sudo chmod 0644 /etc/apt/keyrings/{{KEYRING}}.gpg

A chave fica restrita a este repositório via signed-by: ela não valida nenhuma outra origem do sistema.

Registrar o repositório

ARCH=$(dpkg --print-architecture)
KEY=/etc/apt/keyrings/{{KEYRING}}.gpg
echo "deb [arch=$ARCH signed-by=$KEY] https://{{DOMAIN}} {{SUITE}} {{COMPONENTS}}" \
  | sudo tee /etc/apt/sources.list.d/liptech.list

Em sistemas com suporte a deb822 (Debian 12+, Ubuntu 24.04+) você pode usar o formato novo:

sudo tee /etc/apt/sources.list.d/liptech.sources >/dev/null <<'EOF'
Types: deb
URIs: https://{{DOMAIN}}
Suites: {{SUITE}}
Components: {{COMPONENTS}}
Signed-By: /etc/apt/keyrings/{{KEYRING}}.gpg
EOF

Atualizar e instalar

sudo apt update
sudo apt install <nome-do-pacote>
